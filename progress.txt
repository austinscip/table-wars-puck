## Codebase Patterns
(This section will be updated as we learn patterns during development)

- Flask server runs on port 5001
- WebSocket events use flask-socketio
- Puck firmware uses PlatformIO with Arduino framework
- MPU6050 gyroscope Z-axis for spin detection (rad/s * 57.2958 = deg/s)
- FastLED for WS2812B LED ring (16 LEDs on GPIO 23)
- ESP-NOW for puck-to-puck communication (250m range)
- TV game templates go in server/templates/tv_games/
- Routes for TV games follow pattern: @tv_games_bp.route('/tv/<game-name>/<int:puck_id>')
- Three.js v0.158.0 with UnrealBloomPass for 3D games
- Use _TEMPLATE_3D.html as starting point for new 3D games
