# F1–F4 Games — per-game logic/edge audit (2026-06-06)

Area **F1–F4 games — logic** from `AUDIT-PROGRAM.md` (the runtime games were
covered for disconnect/scoring/serialize in Track G; this is the dedicated
per-game exploit/edge pass). One deep-dive adversarial agent per game
(`speed_pyramid`, `puck_golf`, `puck_racer`, `smash`), grounded in the `Game`
protocol (`runtime/game.py`) and the existing `test_games.py`, then re-graded.

## Big picture

The games are **well-defended**, largely because untrusted puck input is
clamped at the boundary: `runtime/inputs.py` `_num()` rejects NaN/Inf and clamps
`tilt/shake/gyro` to finite ranges before a game ever sees an `InputEvent`. So
the entire "malformed-input → NaN physics / infinite speed / teleport" class is
neutralized upstream, and `get_state()` stays JSON-safe. The MatchManager's
per-match lock + status gating also means games never see concurrent input or
post-finish input. Most agent "CRITICAL"s self-resolved to SOLID on inspection.

## Findings by tier (re-graded)

### HIGH (fixed)

**F-smash-1 — Simultaneous KO drops the killer's credit, corrupting the winner.**
`smash.py` `tick()` integrates positions and resolves KOs **in the same loop**,
marking each ringed-out fighter `eliminated=True` immediately
(`_handle_ko`, line 418). The KO-credit step then skips a killer that is
`eliminated` (line 443) — but when two fighters ring each other out on the
**same tick**, the first one processed is already `eliminated` by the time the
second's KO is credited, so a legitimate KO is silently lost and `final_scores`
(stocks×1000 + kos×200) is wrong → wrong winner. The existing tests
(last-hitter, self-destruct) don't cover it. **Fixed:** snapshot
`eliminated_before` at the **start** of the tick and credit the killer unless
they were out *before* this tick — so a killer who dies the same tick still
earns the KO, while a stale marker from a prior-tick elimination still earns
nothing. Two new regression tests (same-tick double-KO; stale prior-tick
killer).

### LOW (fixed)

**F-golf-1 — Winner lookup could `ValueError` on an empty roster.**
`puck_golf.py:437` did `max(finals.items(), …)[0]` with no empty-guard, while
the sibling path (`on_puck_disconnected`) already guarded with `if finals else
None`. Not reachable through the MatchManager (it enforces `min_players`), but
the inconsistency is a latent crash. **Fixed:** matched the `if finals else
None` guard. Regression test (`PuckGolf([])` finishes without raising).

### Re-graded DOWN / rejected (kept as documented, not fixed)

- **speed_pyramid "HIGH defense gap"** — requires a MatchManager bug (a puck in
  `disconnected` but not in `scores`); not reachable. Scoring/state/serialize/
  disconnect all verified solid (response-time scoring can't go negative; lock-in
  guard prevents double-scoring; finished gates all input; monotonic time stored
  as an elapsed offset and rebased on deserialize).
- **puck_racer "CRITICAL ×6"** — every one self-resolved to SOLID: dt-integrated
  physics (no slow-motion), speed/position bounded by `min/max` (never negative/
  Inf), unknown `puck_index` ignored via `.get()`, JSON-safe rounded state,
  boost can't re-trigger while active, `MAX_RACE_SECONDS` prevents an idle hang.
  The only residual is tie-break-by-dict-order on an exact tie — which is
  **deterministic** (lowest puck_index), not a bug. Left as-is.
- **smash/golf/racer tie-breakers via dict order** — deterministic; not fixed.
- **smash defensive nits** (clear `last_hit_by` on disconnect; clamp deserialized
  `damage_pct`; double-elimination guard) — not reachable in the current call
  graph (eliminated fighters take no input and `_handle_ko` runs once per tick).
  Noted; deferred as low-value hardening.

## Verified solid (keep)

- **Input clamping** (`runtime/inputs.py`) — the keystone defense; finite,
  bounded floats into every game.
- **speed_pyramid** scoring/tier/lock-in/disconnect/serialize.
- **puck_golf** stroke scoring + leaderboard ordering, round-robin turn
  advancement (no deadlock), disconnect-passes-turn, JSON-safe rounded state.
- **puck_racer** dt integration, bounded speed/position, finish/grace/timeout
  win condition, serialize round-trip.
- **smash** the two existing KO-credit tests (last-hitter, self-destruct) hold;
  knockback decay is dt-half-life correct; arena bounds inclusive.

## Deferred (low value)

- smash: clear `last_hit_by` on disconnect, clamp deserialized `damage_pct`,
  `_handle_ko` double-elimination guard — defensive only.
- Explicit fairness tie-breakers (position/finish-time) across games — current
  behavior is deterministic.
